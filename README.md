# Dental Clinic Website — UI/UX Concept

A modern, clean, Arabic (RTL) website concept for a private dental clinic.
This is a **design concept** built to show visual direction, not a live client project.

- **Login:** email, password, remember me, forgot password
- **Register:** full name, email, password + confirmation

## Design notes
- Palette: white, light blue, cool green
- Soft rounded cards, generous whitespace, simple typography (Cairo)
- Full RTL support, responsive (mobile + desktop), light/dark mode
